# Grading contract review

The blind comparison used `comparison-rubric.json`; its grades are retained unchanged in `comparison-grading.json`.

Review found some assertions rewarded wording instead of a decision safeguard: literal rating labels, a multi-item do-not-change list, repeating an unchanged owner, and a generic statement reserving all contracts/hiring to humans. These can penalize concise, substantively equivalent answers. The current eval fixtures replace them with checks of the consequential behavior: recognizing unresolved adoption, preserving evidence provenance, identifying an unjustified intervention and keeping exposure/commitments conditional. A derived workload can state the problem without repeating every input number.

This is a correction to the test contract, not retroactive evidence of improvement. Raw scores have not been silently regraded upward. The additional runs use the current assertions. The memo-length check remains; the revised portal answer exceeded it and a workflow change was tested separately.

The old skill's use of an arbitrary two-condition sourcing rule remains a failure even when it happened to produce a sensible consultant recommendation. The current no-skill baseline made the same sensible recommendation more concisely. Template conformity and willingness to restate disclaimers do not establish incremental value.
