An Agent Skill is a folder of instructions and references. Your supporting AI agent loads it to follow a specific review procedure.

Bring the project notes, constraints, or proposal you already have. Get a short memo with a recommendation, the evidence behind it, and the few missing facts that could change it. You remain responsible for the decision.

01 / AI INVESTMENT

AI Initiative
Evaluator

Should this problem become an AI initiative at all?

  • Compare the strongest non-AI alternative.
  • Check data, error cost, and evaluation readiness.
  • Define the evidence needed for the next investment.
Try an example request

“Our CEO wants an AI agent in every department. Use ai-initiative-evaluator to identify which problem is worth investigating and what evidence we need before committing.”

02 / SOFTWARE DELIVERY

Software Project
Health Review

Status says green. Does the delivery evidence agree?

  • Trace risks to a dated delivery commitment.
  • Separate missing evidence from poor health.
  • Find interventions that can change the outcome.
Try an example request

“The team says everything is on track, but we missed the last three milestones. Use software-project-health-review on these reports to prepare Thursday’s steering decision.”

03 / ENGINEERING SOURCING

Build / Buy /
Hire / Augment

What should you own, buy, or bring in help to deliver?

  • Split the capability into meaningful parts.
  • Compare internal, vendor, and hybrid options fairly.
  • Account for ownership, transition, and exit costs.
Try an example request

“We need a payments integration in five months and hiring takes four. Use build-buy-hire-augment to compare buying infrastructure, hiring an owner, and temporary outside help.”

04 / PROJECT ESTIMATION

Agentic Project
Estimation

When can an agent-assisted team deliver an accepted result?

  • Estimate coding agents, review, and focused human testing.
  • Compare team sizes against real dependencies and capacity.
  • Check company constraints, release readiness, and viability.
Try an example request

“Estimate this portal for one, two and four engineers using coding agents. Our reviewer is part-time and security approval has a fixed window. Use agentic-project-estimation to compare delivery scenarios.”

Read the skill ↗
05 / IDEA VALIDATION

Idea
Validation

Is this idea worth the next commitment, and what would prove it?

  • Ask the few questions that change the verdict.
  • Check alternatives, market, buyer, route, copyability, and AI fit.
  • Get an honest go, test, reshape or stop answer with the cheapest test.
Try an example request

“An engineer wants to build an AI contract-summary tool for small businesses; we have a weekend demo and no customer conversations. Use idea-validation to tell us honestly whether to pursue it and what to test first.”

Start or reload your session as your client requires. Ask it to use ai-initiative-evaluator with your proposal, and confirm that it reads the skill.

Explicit workflow execution has been tested in Codex. Automatic activation and cross-client parity have not been measured.

Inspect the work

Evidence before confidence.

The workflows are designed to challenge a preferred answer, surface contradictions, and avoid invented costs or certainty. “No AI” and “no external partner” are valid conclusions.

We publish scenario fixtures, generated responses, failures, and limitations. The current development evaluation does not establish an overall advantage over a strong model without the skill. Real-world usefulness still needs testing.
